# app-emergency
It’s an emergency alert application designed to help users quickly request assistance in emergency situations

## Google Maps setup

The "Alert Activated" screen displays a Google Map centered on the captured location. To build the app you must
provide a Google Maps API Key by adding the following line to your local (gitignored) `local.properties` file:

```
MAPS_API_KEY=your_google_maps_api_key
```
